Admin del catálogo

Solo tú puedes publicar cambios: hace falta tu clave de GitHub. El público solo ve el catálogo.

1. Conexión con GitHub

¿Cómo saco mi clave?
  1. En GitHub: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories y elige solo tu repositorio del catálogo.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Genera el token, cópialo y pégalo arriba. Se guarda solo en este dispositivo. No lo compartas con nadie.
